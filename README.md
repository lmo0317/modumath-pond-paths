# Pond Paths

Open index.html in a browser. Select two ends of a straight path to cover sand. Undo a strip and compare ways to cover a corner. Each of the four boards has a minimum strip count.

Pond Paths was created by the ModuMath team with OpenAI Codex. NMAI Research may host and serve this standalone game free of charge with its original creator credit. This permission applies to the game file here. All other rights are reserved.

## Try it

[Play the four boards](https://games.betterthanhtml.com/307-pond-paths-modumath.html). Can you cover a corner without counting a tile twice?

For a different kind of practice, students can bring a math problem to [ModuMath](https://math.hjinlabs.com/?lang=en), read the step where they got stuck, then try another problem using the same method. The full service requires signup and uses credits. The four puzzle boards are free to play without signing in.
